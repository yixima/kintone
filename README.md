# kintone 営業管理システム r0414 — 調査記録と分析ツール

株式会社ジャパンプロモーションの kintone（`japanpromotion.cybozu.com`）に蓄積されたデータ、
特に **スペース 11「営業管理システム r0414」** の構造と中身を調査した記録。

## サマリ

- スペース 11 に 8 アプリ、合計 **約 51.5 万レコード**
- 中核は **契約管理(94) 7,204 件・契約金額 42.1 億円**（2010 年〜現在まで途切れなく蓄積）
- 最大は **営業管理(105) 424,774 件** だが、実質は企画別の見込み客リスト
  （商談内容の記録は 1.3%、営業フェーズ設定は 2024 年以降で 20.3%）
- **請求管理(95)・入金管理(96) は 2019 年で更新停止**。売上と回収の突合が kintone 上でできない
- 顧客マスタ(89) 76,138 件のうち契約実績があるのは 3,914 名（5.1%）

## ツール

```bash
cp .env.example .env      # 認証情報を記入（.env は Git 管理外）
export $(grep -v '^#' .env | xargs)

python3 tools/dump_schema.py > docs/02_アプリ別スキーマ.md   # スキーマ再生成
python3 tools/profile.py                                     # データプロファイル再集計
```

`tools/kintone_client.py` に REST API の薄いラッパを置いている。
認証情報は環境変数からのみ読み込み、リポジトリには一切含めない。

## 注意

このリポジトリには kintone の**認証情報も実データも含まない**。
顧客の氏名・住所・電話番号・メールアドレスといった個人情報を扱うため、
取得したデータをローカルへ書き出す場合は `data/`（`.gitignore` 済み）配下に置き、
リポジトリへコミットしないこと。
