# データプロファイル（実測値）

調査日 2026-08-20。契約管理・請求管理・入金管理・プロジェクトマスタ・パッケージマスタ・顧客マスタは
**全件取得して集計**。営業管理(105) は 42 万件あるため、2024 年以降の 112,503 件を全件取得し、
それ以前は API の件数クエリで集計した。

> **注意 — 件数クエリの信頼性**
> 営業管理(105) のようにレコード数が極端に多いアプリでは、`フィールド != ""` を条件にした
> `totalCount` が実測と一致しない事例を確認した（`顧客ID = ""` が 268,934 件、
> `顧客ID != ""` が 424,703 件と、合計が総レコード数 424,774 件を大きく超える）。
> 実データを取得して数えた結果、正しいのは `= ""`（空の件数）側だった。
> 本ドキュメントの入力率はすべて **実データを数えた値**、または日付条件と併用した件数クエリの値。
